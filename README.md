# DevTermSetup

一键配置开发终端环境：代理、WezTerm、Neovim、lazygit、herdr。

## 使用

### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/BowiEgo/DevTermSetup/main/setup.sh | bash
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/BowiEgo/DevTermSetup/main/setup.ps1 | iex
```

### 本地执行（保留代理到当前会话）

```bash
git clone https://github.com/BowiEgo/DevTermSetup.git && cd DevTermSetup
source ./setup.sh
```
